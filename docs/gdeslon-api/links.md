# Ссылки, sub_id, парковка доменов, TrafficBack

Источники: https://gdeslon.ru/faq/17/, /faq/23/, /faq/22/, /faq/27/ · Контекст: Shared

API у этих инструментов нет — они настраиваются в кабинете. Для библиотеки важны форматы.

## Партнёрские ссылки и диплинки

Партнёрская ссылка ведёт через трекинг-домен `https://f.gdeslon.ru/cf/...`; с припаркованным доменом —
`https://<ваш-домен>/f/...`.

Факт (проверено 2026-10-07): ссылки магазинов — `https://sf.gdeslon.ru/cf/<код вебмастера>?erid=…&mid=…`
([merchants.md](merchants.md)); ссылки офферов поиска — `https://af.gdeslon.ru/cm/<код вебмастера>/?mid=…&goto=<URL товара>&erid=…`;
с `parked_domain_name=http://example.com` — `http://example.com/cm/<код вебмастера>/?…` ([search.md](search.md)).
`<код вебмастера>` (10 hex) один во всех ссылках — персональные данные, в фикстурах заменяется на `0a1b2c3d4e`. Диплинк — партнёрская ссылка на любую страницу магазина (главная, раздел),
создаётся в кабинете (`/deeplinks/`). Алгоритм построения ссылки публично не описан —
**ссылки сами не генерируем**, берём готовые из API (поиск, магазины, фиды).

## sub_id

Метки источника трафика: `sub_id`, `sub_id2`, `sub_id3`, `sub_id4`, `sub_id5` — параметры, дописываемые к
партнёрской ссылке. Попадают в отчёты, заказы (`sub_id`) и postback (`*sub_id*` … `*sub_id5*`).

Факты (проверено 2026-10-11, задача affiliate-link):

- FAQ 23 (перечитан живьём) — только «добавив к партнёрской ссылке один или несколько параметров sub_id. Всего их 5».
  **Ограничений длины и допустимых символов в документации нет**; живьём их не проверить без перехода по ссылке
  (это клик в статистике) — **лимиты API не подтверждены**.
- В ссылках, которые отдаёт API для SDK, `sub_id` нет ни у одной: офферы поиска (317), магазины `shops.xml` (141),
  купоны `coupons.xml` (`url` и `url-with-code`, 944). Параметр `sub_id` в запросе поиска игнорируется
  (`search.xml?l=3&sub_id=…` — те же байты, что без него).
- JSON-купоны `/api/v1/coupons/` (SDK не использует): у всех 959 `url` и `url_with_code` — `?sub_id=None` первым
  параметром (Python `None` строкой), `erid` нет.
- Формы query (все без `#fragment`, без порта, без повторов ключей): оффер — `?mid=<id>&goto=<URL, %-кодирован>[&erid=<erid>]`
  (в `goto` бывает сырой `!`; сырых `&`, `#` нет); магазин — `?erid=<erid или пусто>&mid=<id>`; купон —
  `?erid=<erid>` или `?kc=<код, %-кодирован, бывает %0A>&erid=<erid>`.
- Что принимает трекер на `/cm/`, `/cf/`, `/ck/` с дописанным `sub_id` — по документации (FAQ 23); наличие
  `sub_id=None` в JSON-ссылках купонов косвенно подтверждает, что `/ck/` параметр знает.

Правило SDK (ограничение библиотеки, не API): значение `sub_id` — `[A-Za-z0-9_-]{1,64}` (unreserved-символы URL,
кодирование не нужно); номер — 1…5. Другой формат дописывайте к ссылке сами.

## Парковка доменов

Свой домен вместо `f.gdeslon.ru`: в DNS две A-записи `31.184.219.58` и `5.189.239.194` (и никаких других),
привязка до 72 часов, нужен SSL. В поиск домен передаётся параметром `parked_domain_name`.

## TrafficBack

Перенаправление трафика выключенного рекламодателя на другой магазин/URL (один целевой URL на магазин).
Только кабинет.
